# Theatre Booking System (Java)

A Theatre Booking System developed in Java using custom-built linked lists and JavaFX.

## Features
- Add and manage shows
- Add and manage performances
- Customer management system
- Seat booking with availability tracking
- Prevents double booking
- Cancel bookings
- Save and load system data using XML
- JavaFX graphical user interface
- Unit testing using JUnit

## Technologies Used
- Java
- JavaFX
- Maven
- Custom Linked List Data Structure
- XML File Storage
- JUnit Testing

## Purpose
This project was developed as part of a Data Structures and Algorithms module to demonstrate implementation of custom data structures without using Java Collections.
